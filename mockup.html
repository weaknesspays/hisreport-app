ข้อกำหนดระบบ HIS Report (ร่างก่อนพัฒนา)

รวมแนวทางจาก HOSxP Report Central/Report Designer, เครื่องมือรายงาน SQL (PHP Reports, Redash, Metabase), รูปแบบตัวชี้วัด HDC และระบบ his_reporter เดิมในเครื่อง

1. ที่มาของแนวคิด

แหล่งสิ่งที่นำมาใช้
HOSxP Report Central / Report Designerรายงานแบ่งหมวดหมู่, แยก System Report กับ Custom Report, รายงานเก็บในฐานข้อมูล, นำเข้า/ส่งออกรายงานเป็นไฟล์แชร์ระหว่าง รพ., รายงานตรวจคุณภาพข้อมูล
PHP Reports / Redash / Metabaseตัวแปรใน SQL หลายชนิด (วันที่, ช่วงวันที่, dropdown, dropdown จาก SQL, หลายค่า), เงื่อนไขเสริม [[ ]], ตัวกรองระดับ Dashboard ใช้ร่วมทุก widget, จัดรูปแบบคอลัมน์, drill-down ไปรายงานอื่น, แถวรวม, cache ต่อรายงาน, ลิงก์แชร์พร้อมเงื่อนไข
HDC กระทรวงสาธารณสุขรูปแบบตัวชี้วัด เป้าหมาย → ผลงาน → ร้อยละ, เกณฑ์ผ่าน/ไม่ผ่าน, drill-down รายพื้นที่, แยกไตรมาส/ปีงบ
his_reporter (ระบบเดิมในเครื่อง)คำขอรายงาน + ติดตามสถานะ + ความเร่งด่วน, log การเปิด/ดาวน์โหลด, หมวด/หัวข้อ 2 ระดับ
hisreport 9.1–9.6 (ที่ทำแล้ว)ตารางเทียบปีงบหลายคอลัมน์, cache ปีที่ปิดแล้ว, ข้อมูลกรอกเอง (SEMI-ICU), connection แบบ READ ONLY

3. ความปลอดภัยและ PDPA

  • เชื่อม HIS ด้วยผู้ใช้ที่มีสิทธิ์ SELECT เท่านั้น + SET SESSION TRANSACTION READ ONLY; ตรวจ SQL ต้องขึ้นต้นด้วย SELECT/WITH และห้ามมีหลายคำสั่ง
  • ค่าตัวแปรส่งแบบ prepared statement เสมอ (ไม่ต่อ string)
  • จำกัดเวลารัน (max_statement_time) และจำนวนแถว ต่อรายงาน
  • คอลัมน์ที่ติดป้าย "ข้อมูลส่วนบุคคล" ปิดบังอัตโนมัติสำหรับ Role ที่ไม่มีสิทธิ์ (ทั้งบนจอและใน Excel)
  • บันทึก log: เข้าสู่ระบบ, เปิดรายงาน (เงื่อนไข, จำนวนแถว, เวลา), Export, แก้ไขรายงาน/สิทธิ์, ถูกปฏิเสธสิทธิ์
  • ไฟล์ Excel มีหัวกระดาษ: ชื่อรายงาน, เงื่อนไข, ผู้ส่งออก, วันเวลา

5. ลำดับการพัฒนาที่แนะนำ

  1. ฐานข้อมูลระบบ + login ด้วยผู้ใช้ HIS + Role/สิทธิ์ + log
  2. ตัวรันรายงาน: แทนตัวแปร, เงื่อนไขเสริม, ตาราง/ตัวเลข/กราฟ, Export Excel
  3. หน้าจัดการรายงาน + ทดสอบ + เวอร์ชัน + นำเข้าจาก rep_query_item
  4. Dashboard (เลือก widget, ตัวกรองร่วม, แชร์) + ย้ายรายงาน 9.1–9.6 เข้าระบบ
  5. คำขอรายงาน, KPI/เป้าหมาย, ตั้งเวลาประมวลผลล่วงหน้า

6. สิ่งที่ต้องยืนยันก่อนเริ่ม

  • ฐานข้อมูลของระบบ (ข้อ 4) จะสร้างที่ไหน — schema ใหม่บน 10.0.0.8 หรือเครื่องนี้
  • ตารางผู้ใช้และวิธีเข้ารหัสรหัสผ่านของ HIS (เพื่อ login ด้วยบัญชี HIS)
  • นำเข้าคิวรี่เดิม 221 รายการจาก rep_query_item หรือไม่ / item_id กับ level_id หมายถึงอะไร
  • มีฐาน Replica สำหรับรายงานหนักหรือไม่
